# CLAUDE.md — cuponmanialatina

Repositorio de **CupónMania Latina**, por ahora solo con un README.

CupónMania Latina invierte en marketing digital para llenar locales comerciales latinos,
con acuerdos parametrizados por promotores internos e inicio de sesión con Google.

## Dónde está el código
El código de la aplicación web vive en el repositorio **`jhonathanmaster/Prototipo-v1.1`**
(React + Vite + Firebase). Si te piden cambios en la app, trabaja allí, salvo que el usuario
diga que quiere mover el código a este repositorio.

## Si se migra el código aquí
- Copia el proyecto completo de `Prototipo-v1.1` (incluido su `CLAUDE.md`) y actualiza este archivo.
- Confirma con el usuario antes de dejar de usar `Prototipo-v1.1`.
